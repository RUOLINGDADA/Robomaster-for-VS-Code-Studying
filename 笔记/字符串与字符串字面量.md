# 一.字符串与字符串字面量

**字符串字面量**就是源码里直接用双引号写出来的东西：

```c
"motor1"
"hello"
"OK\n"
```

它们在编译时就已经确定内容，通常会被放进程序镜像，最后烧到 Flash 里。

**C 字符串**是运行时内存里一段以 `'\0'` 结尾的 `char` 序列，例如：

```c
char buf[8];

buf[0] = 'm';
buf[1] = 'o';
buf[2] = 't';
buf[3] = 'o';
buf[4] = 'r';
buf[5] = '1';
buf[6] = '\0';
```

这时 `buf` 里面的内容就是一个 C 字符串，但它不是字符串字面量。

所以关系是：

```text
字符串字面量 -> 源码里的 "xxx"
C 字符串     -> 内存里的 char 序列，以 '\0' 结尾
```

可以这么总结：

```text
字符串字面量通常可以作为 C 字符串使用；
但 C 字符串不一定来自字符串字面量。
```

唯一要小心一句话：**字符串字面量本身不一定“可修改”**。它虽然表现为一串字符，但通常在 Flash / `.rodata`，应该当成只读。

例如：

```c
char *p = "motor1";
```

`"motor1"` 是字符串字面量，也是一个 C 字符串，但不该修改。

```c
char arr[] = "motor1";
```

`"motor1"` 是字符串字面量；`arr` 里面拷贝出来的内容是另一个 C 字符串，可以修改。



# 二.字符串字面量从程序烧录到启动内存布局

```c
char *gp = "global_ptr";
static char gsarr[] = "global_arr";

int main(void)
{
    char *p = "motor1";
    char arr[] = "motor2";
    static char sarr[] = "motor3";

    p[0] = 'M';      // 危险
    arr[0] = 'M';    // 可以
    sarr[0] = 'M';   // 可以
}
```

**1. 编译/链接后，程序镜像里有什么**

程序镜像最终会被组织成几个段，大概是：

```text
Flash 中的程序镜像:

.text
  机器指令
  中断向量表
  Reset_Handler
  main 的代码

.rodata
  "global_ptr\0"
  "motor1\0"
  其他只读常量

.data 的初始值镜像
  gp 的初始值 = "global_ptr" 的地址
  gsarr 初始内容 = {'g','l','o','b','a','l','_','a','r','r','\0'}
  sarr 初始内容 = {'m','o','t','o','r','3','\0'}

可能还有用于初始化局部 arr 的常量数据
  "motor2\0"
```

注意：`.data` 的**运行位置**在 RAM，但它的**初始值**必须先存放在 Flash 里的程序镜像中。否则掉电后 RAM 内容没了，程序下次启动不知道 `.data` 初值是什么。

---

**2. 烧录进 Flash 后**

烧录完成后，Flash 里大概是：

```text
Flash:
0x08000000  中断向量表
0x08000xxx  .text 代码
0x0800xxxx  .rodata 只读字符串
0x0800xxxx  .data 初始值镜像
```

此时 RAM 还没有被初始化，程序也还没运行。

---

**3. MCU 复位后，进入 main 之前**

复位后先执行启动代码，一般是 `Reset_Handler`。

启动代码会做几件重要的事：

```text
1. 设置栈指针 SP
2. 把 .data 初始值从 Flash 拷贝到 RAM
3. 把 .bss 清零
4. 调用 SystemInit()
5. 调用 main()
```

所以进入 `main()` 之前，内存大概变成：

```text
Flash:
  .text
  .rodata:
    "global_ptr\0"
    "motor1\0"
  .data 初始值镜像:
    gp 初始值
    gsarr 初始内容
    sarr 初始内容

RAM:
  .data:
    gp = 指向 Flash 中 "global_ptr\0"
    gsarr = {'g','l','o','b','a','l','_','a','r','r','\0'}
    sarr = {'m','o','t','o','r','3','\0'}

  .bss:
    未初始化的全局/static 变量，已清零

  stack:
    还没创建 main 里的局部变量
```

---

**4. 执行到 `main()` 里的局部变量**

执行：

```c
char *p = "motor1";
```

结果是：

```text
RAM stack:
  p = Flash 中 "motor1\0" 的地址

Flash .rodata:
  "motor1\0"
```

所以：

```c
p[0] = 'M';
```

是在改 Flash 里的 `"motor1"`，危险，可能 HardFault。

但：

```c
p = "M";
```

只是修改栈上的指针变量 `p`，让它指向另一个字符串字面量，这没问题。

---

执行：

```c
char arr[] = "motor2";
```

结果是：

```text
RAM stack:
  arr = {'m','o','t','o','r','2','\0'}
```

这个数组整体在栈上。初始化时，编译器会生成代码，把 `"motor2\0"` 这几个字节写入栈上的 `arr`。

所以：

```c
arr[0] = 'M';
```

改的是 RAM 栈上的副本，可以。

---

执行：

```c
static char sarr[] = "motor3";
```

注意：它不会执行到这一句时才分配。

因为 `sarr` 是 `static`，它在进入 `main()` 之前已经由启动代码初始化好了：

```text
RAM .data:
  sarr = {'m','o','t','o','r','3','\0'}
```

所以：

```c
sarr[0] = 'M';
```

改的是 RAM `.data` 里的内容，可以。

---

最终对比：

```c
char *p = "motor1";
```

指针 `p` 在栈上，字符串 `"motor1"` 在 Flash `.rodata`，不能通过 `p` 改字符串内容。

```c
char arr[] = "motor2";
```

数组 `arr` 在栈上，内容是运行时初始化出来的 RAM 副本，可以改。

```c
static char sarr[] = "motor3";
```

数组 `sarr` 在 RAM `.data`，初值来自 Flash，启动时已经复制完成，可以改。

核心区别就是：**指针初始化只是保存地址；数组初始化会创建一份自己的存储空间。**
