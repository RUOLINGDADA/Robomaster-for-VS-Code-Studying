# 待确认需求

下面的问题会影响后续目录、任务和接口设计。用户确认后，agent 应更新本文件和 `PROJECT_CONTEXT.md`，再把结论应用到代码。

## 硬件与目标功能

1. 云台包含哪些执行器和传感器？例如 C620/M3508、GM6020、BMI088、磁力计、编码器、遥控器等，具体型号和数量是什么？
2. 当前板卡是 RoboMaster 开发板 C 型还是自定义 STM32F407 板？外设实例、引脚、晶振和 CAN/串口波特率是否已有接线表？
3. 第一阶段最优先落地哪个可验收功能：底层 CAN、单电机闭环、IMU、遥控器、云台姿态控制，还是任务框架？
4. 是否需要保留 SEGGER RTT？日志默认输出到 RTT、串口，还是完全关闭？
5. `task_feed_motor` 当前按 CAN1 电机 ID 1、上弹 `+3000`、下弹 `-3000` 原始电流进行低速自循环测试；实机确认后，电机 ID、正方向和安全测试电流是否需要调整？
