# 通用 GM6020 云台轴

## 当前 Yaw 边界策略

正式 Yaw 默认 `YAW_BOUNDARY_YIELD_ENABLE=1`：115～4085 count 边界处丢弃不可达的向外目标误差，清向外积分，并在 Ramp 后禁止向外逻辑电流。先让步再积分人工输入，反向当周期接受；底盘反转后保持让步形成的新航向，不追赶原目标。IMU 真实连续航向不变。Pitch 保留只过滤人工命令的策略，固定机械角测试关闭让步。接口、18219 项主机检查、日志开关和用户上板验收见 [Yaw 边界让步](yaw_boundary_yield.md)；下方早期记录中的“两轴不裁剪输出”仅是当时基线。

## 2026-10-19 历史：人工下界余量与鼠标降速

用户已确认两轴方向正常，Yaw=-1/Pitch=+1保留。Pitch实测下挡块8184～8187高于旧下界8136，现人工下界8250留约2.8～2.9°；鼠标增益Yaw=0.2、Pitch=0.05‰/count、上限100‰，仅鼠标目标移动速度最高4 rpm。没有增加边界输出裁剪或目标重定位，也没有调整PID/补偿。正式链回归/构建通过，真实触底抖动及余量待验收，见[当前报告](pitch_stop_mouse_speed_20261019.md)。

## 当前行为：六轴惯性保持

正式 Yaw/Pitch 启用 BMI088 六轴自稳。进入时分别锁定当时的惯性角；人工速度改变保存目标，行程内零输入或命令超时冻结目标。Yaw 边界让步是目标冻结的例外；范围外可捕获当前姿态，但不允许继续向外施力。Pitch 保留范围外纠偏和补偿。磁采集、磁融合及磁诊断暂停，保留已有参数。

`GimbalControl_FeedbackTypeDef` 分开保存控制角 `angle_raw`（等效 count）、同参考系速度 `speed_rpm` 和真实机械角 `mechanical_angle_raw`（count）。惯性角乘 `8192/360`，惯性角速度乘 `60/(2π)`；现有 PID、滤波、补偿、限流和 Ramp 数值保持。Yaw 使用 `yaw_total_deg`，不会在 ±180°回绕时跳目标。ZYX 关系中 `Pitchdot=q*cos(Roll)-r*sin(Roll)`、`Yawdot=(q*sin(Roll)+r*cos(Roll))/cos(Pitch)`；不能直接把机体系 gyroY/gyroZ 当欧拉角速度。

### 人工增量限位

控制与日志使用同周期编码器快照。实际编码器到达/越过下界时拒绝负输入，到达/越过上界时拒绝正输入，反向输入当周期完整接受。在范围内用 `机械角+保存目标-控制角` 估计该目标对应的机械角，只缩小本次非零人工增量，使其不继续越界；已在范围外的目标不自动拉回。接受增量换回有效命令 rpm，同时供目标积分和速度前馈使用。

零输入跳过人工增量处理；惯性目标从不直接与机械 min/max 比较。`command_limited` 仅说明人工命令受限。启用让步时，先根据机械边界及目标误差方向丢弃不可达目标，最后在 Ramp 后限制向外电流。`target_yielded` 和 `outward_current_limited` 单独记录，不关闭正常输出许可。固定机械角测试继续独立检查配置目标范围。

### 反馈切换与故障

每个轴任务独占控制器，以既有 2 ms 周期各取一份 CAN/INS 快照。INS 由唯一 INS 任务发布，跨任务通过短临界区复制；采样年龄及资格窗口均用 HAL 毫秒，调度用 FreeRTOS Tick。

| 条件 | 目标与输出 |
| --- | --- |
| 首个有效 CAN 反馈 | 捕获当前编码器角，首周期零电流；范围外也可保持 |
| IMU 无效/过期/重置 | 捕获一次当前编码器角并保持，暂停人工运动；不逐周期追随实际位置 |
| READY、有效、陀螺/加计年龄均≤10 ms且样本持续更新100 ms | 捕获当时惯性角进入自稳，切换周期暂停输入 |
| 绝对 Pitch≥80° | 编码器降级，避免欧拉测速奇异；回到≤75°后重新资格确认 |
| CAN 丢失 | 立即请求零电流，恢复首周期清历史并零输出；INS参考连续时保留目标 |
| CAN 中断期间 INS 失效或重置 | 记住降级请求，恢复真实编码器后捕获机械角，再重新资格确认 |
| 标定许可、参数或控制数值非法 | 请求零电流 |

`GimbalControl_Reanchor()` 只在参考切换边沿捕获角度，清两级积分并用新来源速度初始化滤波，保留当前电流 Ramp。CAN 恢复的旧规则仍清 Ramp，从零重新爬坡。`*_STABILIZATION_ENABLE=0` 可选编码器正式保持；`RunFixedTarget()` 始终绕过 INS。

两轴新增配置均位于各自任务 config：`*_STABILIZATION_ENABLE`（0/1）、`*_IMU_FEEDBACK_SIGN`（±1，当前Yaw=-1、Pitch=+1）、`*_IMU_READY_MS`（>0，当前100 ms）、`*_IMU_TIMEOUT_MS`（>0且小于资格窗口，当前10 ms）、`*_IMU_EXIT_PITCH_DEG`（0~90°内，当前80°）、`*_IMU_ENTER_PITCH_DEG`（>0且小于退出阈值，当前75°）。这些值分别控制反馈选用、方向、资格时长、新鲜度及奇异区迟滞；不改变现有标定与增益。

2026-10-19零电流实测确认Yaw与编码器反向，已把Yaw映射改-1；Pitch用户确认正常，保留+1。角度与欧拉角速度使用同一映射；物理右转为正不能代替编码器增量核对。旧+1在实测保持窗口回归中产生同向加剧电流，新-1反向纠偏；修正后的带载效果待验收，见[方向报告](../ins/yaw_runaway_20261019.md)。

## 职责与依赖

`Core/Inc/app/gimbal/`、`Core/Src/app/gimbal/` 保存正式共用实现：

- `gimbal_command.h`：轴无关相对速度命令数据，不发布 Yaw/Pitch 命令。
- `gimbal_control`：目标积分、位置 PID、速度 PID、算法补偿合成、限幅和电流 Ramp，复用 algorithm 中的 PID/滤波/Ramp/重力补偿。
- 前馈系数、位置 I/D、速度 D 及两级积分独立限幅由各轴配置提供；速度滤波权重独立设置，测试与正式共用这些参数。
- 软件限位由 `gimbal_control` 过滤人工增量及对应速度前馈；可选 `boundary_yield_enabled` 增加边界目标让步和最终电流方向门，仅正式 Yaw 默认启用。
- `gimbal_axis`：初始化、每周期各一次CAN/INS快照、反馈切换、输出和日志适配。

只在任务上下文运行，没有具体任务头文件依赖。当前两轴反馈由 CAN2 ISR 更新，ISR 不运行控制或打印；CAN 句柄由各轴任务配置传入，CAN1 承载独立四轮底盘。

## API 与数据流

`GimbalAxis_Init(&axis, &config)` 复制本轴电机、标定和控制参数；角度范围与首帧参考
自动从标定生成。标定无效允许只读模式，闭环始终零输出。

`GimbalAxis_RunCycle()` 接收已处理超时的相对命令；`GimbalAxis_RunFixedTarget()` 接收固定连续角度。
两者调用同一运行流程；每周期 Process → CAN快照一次 → 正式模式INS快照一次 → 检查配置/新鲜度 → 控制 → 提交。
首帧、CAN恢复和配置无效时走安全零输出；CAN恢复清动态历史，参考连续时先保留最后目标，下一输出周期仍检查 Yaw 边界让步。向内人工命令当周期接受。固定目标越界直接零输出，合法固定目标不启用让步。

`axis.cycle` 包含唯一快照、计算结果、最终目标电流、许可及 CAN 提交结果，日志复用它。
任务和固定目标测试使用 `app/log/gimbal_log.h` 的共用格式，从本周期 `axis->cycle` 生成日志参数，
直接调用 `LOG_TRY_PRINTF()`；不重新读驱动，忙时返回 false，下次周期重试。Yaw/Pitch 日志开关独立。
轴运行时会把 GM6020 原始转速按该轴独立的反馈速度符号映射为连续角度的逻辑转速；反馈方向和电流方向不能共用一个符号，否则下滑可能被误认为向内运动。

## 恢复语义

正式人工速度按边界过滤增量与前馈；行程内回中保持目标，Yaw 到边界后按需让步，向内输入同周期接受。固定机械角测试独立检查目标范围。CAN掉线清零，恢复清历史后再执行本轴边界策略；IMU故障转编码器保持，重入惯性时捕获新姿态。

## 坐标与调参

8192 计数/圈；机械测试目标以标定中位为参考，惯性目标以INS当前参考系为准。编码器首帧按“离中心最近的单圈解释”映射，启动位置需要距中心
不到半圈；这不是机械总范围必须小于半圈。存在传动机构必须记录电机轴/机构轴传动比。

控制器和日志对象按轴独立。标定与增益放各自任务配置，测试仅提供输入意图，
确认参数后切换正式入口即可。正式模式使用惯性姿态保持；启动/故障降级及固定目标测试使用机械相对角。实际精度与负载增益待上板验证。

Pitch 与 Yaw 的控制参数按负载分开。当前 Pitch 的自动重力补偿开关为 1，
由独立算法模块叠加 `bias + amplitude*cos(angle_offset)`；Yaw 使用同一模块但禁用。
补偿与闭环电流合成后统一限幅并经过 Ramp，方向由独立的补偿符号控制。
Pitch 与 Yaw 都保留反馈掉线、标定有效性和总电流上限检查；正式 Yaw 仅将边界向外电流置零，向内仍可输出。
Yaw 与 Pitch 都不再启用堵转候选、锁存和恢复流程。

Pitch 达到或越过边界时只忽略继续向外的输入，保持保存目标并运行闭环。正式 Yaw 同时丢弃向外目标误差并限制向外电流；范围外启动不自动回中。边界事件不是故障，不关闭输出许可；反馈掉线、参数无效或测试目标无效时安全门仍立即清零。

速度目标为 `clamp(位置 P × 角度误差 + 位置 I × 误差积分 + 位置 D × 角度误差变化率 + 前馈系数 × 命令速度)`；
位置 D 的误差变化率由目标角速度减实际滤波速度换算得到，固定目标时就是实际速度的阻尼项。
目标积分不乘前馈系数；固定目标的命令速度为零，前馈贡献为零。速度环 D 由轴配置选择；积分限幅
允许 0，但不可大于总电流限幅。运行时拒绝非有限/负增益及无效滤波权重，拒绝后保持零输出。

## 验证

用临时主机 HAL 替身编译实际 C 源码，验证回绕、双轴槽位隔离、目标/保持/Ramp、方向限位、
快照失败、限位过滤、最后目标保持和反向输入、掉线安全周期及 UART DMA 缓冲区所有权。
临时验证文件保存在系统 Temp，不加入工程；主机检查不能证明实际电机方向、机械安全范围或负载增益正确。

## 控制参数单位与饱和检查

每轴的调参宏保留在对应任务配置；输入鼠标灵敏度在 DBUS 任务配置。
位置环误差使用当前参考系的等效 count（机械测试为编码器 count），速度目标使用 rpm，电流使用 GM6020 原始值。
位置 P 的单项饱和阈值为 `MAX_SPEED_TARGET_RPM/POSITION_KP_RPM_PER_RAW` count；
速度 P 的单项饱和阈值为 `MAX_CURRENT_RAW/SPEED_KP_CURRENT_PER_RPM` rpm。
I、D、前馈和重力补偿会占用输出余量，实际饱和可能更早。

命令速度既积分目标角度，也经前馈参与目标速度。只调整前馈不改变目标积分；
固定目标速度为零时没有速度前馈。按实际 dt 积分，电流斜率使用 raw/s。
官方例程的 rad/s 或每周期积分增益须先换单位，再写入任务配置：
`rad/s × 60/(2π)` 得 rpm，`count × 2π/8192` 得 rad。
先检查速度和电流是否饱和，再逐项调增益；饱和时继续加 P 只会增加力矩或温升。
