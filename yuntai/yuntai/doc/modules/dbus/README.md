# DBUS 遥控输入

## 摇杆与鼠标输入采集

串口助手设为 **921600 baud、8N1、UTF-8**，打开原文保存后复位开始采集。`.ioc` 保存 USART1 波特率；`usart.c` 的 `USART1_Init 2` 用户区在再次 CubeMX 生成前应用同一波特率，生成区保持不变。USART3 接收协议保持100000 baud、偶校验。

`LOG_DBUS_TRACE_ENABLE=1` 时只输出输入采集分类，其他设备日志暂停，控制任务仍正常执行。关闭后恢复 `log_config.h` 中原有分类设置。与 MotionCal 同时开启时，MotionCal 优先独占日志。输入算法及增益不因采集而调整，启动说明输出实际编译配置。

接收层 `Dbus_ProcessObserved()` 在每份合法帧提交后、临界区外调用观察者。观察者只复制数据，不消费鼠标增量、不打印。原有 `Dbus_Process()` 使用空观察者，原有快照与累计规则保留。DBUS 任务发布完四个命令后，用同周期快照和已发布值记录命令。没有新帧时仍逐2 ms周期检查回中和许可变化，未变化时100 ms留一条心跳。命令比较精度为0.001‰；新合法帧即使数值相同也保留原始帧和一次命令记录。

记录为固定列 CSV，串口先输出中文字段说明。数值行省去重复字段名，提高有效带宽。

| 行首 | 后续字段顺序 |
| --- | --- |
| `R` | 记录序号，接收帧序号，接收ms，接收周期计数，帧间隔us，CH0，CH1，CH2，CH3，CH4，鼠标X，鼠标Y，鼠标Z，键盘位图，按键拨杆位图 |
| `C` | 记录序号，引用帧序号，记录ms，记录周期计数，算法ms，引用接收ms，累计鼠标X，累计鼠标Y，累计帧数，虚拟X，虚拟Y，Yaw命令，Pitch命令，状态位图 |
| `S` | 统计ms，合法帧，非法帧，接收溢出，重同步，串口错误，DMA错误，启动错误，日志丢样，待发，最大待发，提交拒绝，已提交记录 |

CH0~4 是减去1024后的原始计数；鼠标量为有符号相对位移count。C行四个输出采用 **0.001‰**，例如`500`是`0.5‰`；日志量化不回写算法。CH0/1按任务配置死区和方向映射后与虚拟X/Y合成，原始帧与命令通过引用帧序号关联。累计帧数大于1时，R行逐帧保留原始变化，C行展示本周期实际交给算法的累计量。无效浮点输出用`-2147483648`表示，不把它当实际命令。

R位图：bit0~1左拨杆，bit2~3右拨杆，bit4鼠标左键，bit5右键。C位图：bit0接收在线，bit1云台命令有效，bit2虚拟鼠标启用；bit4~5为X阶段、bit6~7为Y阶段。阶段0空闲、1保持、2回中、3本周期新输入。

接收ms及周期计数在完整DMA帧ISR中保存，表示 MCU 观察到完整帧的时刻，包含中断响应延迟，并非遥控器物理采样时刻。记录ms/周期计数在命令发布后保存，算法ms是原控制计算时刻，不能拿串口助手显示时间替代。DWT启用但不清零，与INS共用同一时基；计数频率在启动说明中给出，当前168 MHz下约25.57 s回绕。短间隔用无符号周期差除频率，帧间隔us取整到1 us；首帧、时钟非法或接收间隔达到1 s时用`4294967295`表示未知。分析跨长停顿用HAL ms定位，不能只用一圈周期差计算；两种时间计数都允许回绕。

采集缓冲由DBUS任务独占，128条×60字节=7680字节，文本暂存704字节。每次只提交完整行，共用唯一`Log_TryPrintf`后端；DMA接受后才出队，忙时继续接收/发布，禁止等待串口。日志缓冲满时丢新诊断记录并递增“日志丢样”，记录序号也留下缺口；这与ISR接收邮箱“接收溢出”分别计数。提交拒绝只表示这次没有交给DMA，不代表数据丢失；已提交也不保证USB串口或PC最终保存。所有统计每秒输出，需检查日志丢样和接收溢出是否增长。

建议每组先静止2秒，再分别采集：真实摇杆小推/回中、慢推/快推/反向；鼠标轻划/连续移动/停手/反向。每次只动一轴，保留动作前后原始日志并注明方向与大致时段。当前跟手映射按接收间隔测速，新零帧直接清本轴；无新帧时保持14 ms、回中14 ms。两份原日志及实际C回放见[输入分析](../mouse_virtual_joystick/input_trace_analysis_20261019.md)，新模式手感待用户烧录复测。

临时主机使用真实DBUS接收/解码、任务适配、鼠标算法及采集实现，通过3015项检查：多帧累计、ISR时间保留、坏帧拒绝、保持/回中/离线、忙时不出队、溢出不影响控制、HAL/DWT回绕、整数极值及整行长度。5秒约143 Hz接收、2 ms调度并模拟921600 baud DMA占用时未新增日志丢样；最大接受批次680字节。主机出现的三条指针截断警告来自32位MCU DMA地址在64位主机替身中转换，未生成或验证ARM固件；真实串口带宽、运行负载和上位机完整接收仍待上板。

`Core/Inc|Src/bsp/dbus` 使用 USART3 PC11、100000 baud、9B+偶校验、DMA1 Stream1
双缓冲接收 18 字节 DJI DBUS 帧。9B 包含 8 位数据和 1 位校验；配置成 8B+偶校验会
把数据最高位当成校验位，摇杆高位出现时会产生错误控制量。

DMA 中断只复制完成块到固定 16 槽静态环形邮箱，`task_dbus` 每 2 ms 解码并发布一次
Yaw CH0、Pitch CH1 命令。覆盖邮箱只保留最新状态，避免积压旧摇杆动作；命令时间戳
使用接收时刻，100 ms 没有合法帧即掉线。DBUS 掉线或快照失效使命令失效：云台停止
目标移动并保持位置，供弹与底盘停止；云台 CAN 反馈掉线才清零。鼠标 X/Y 由虚拟摇杆模块
按合法帧序列只消费一次，以本批位移/接收间隔得到速度并替换旧值；新帧零值清本轴，无新帧时按任务配置保持并线性回中。
DBUS 合法帧先进入固定环形邮箱，再由任务一次排空并累计本周期的
`mouse_delta_x/y`。快照时间使用最后一帧接收时刻，避免积压帧因旧时间戳立即进入回中。
邮箱满时递增 `frame_overruns`；日志能区分累计输入和真实丢帧。
摇杆与虚拟鼠标速度合成后限制为 ±1000‰；鼠标左键发布按钮状态，供弹任务判断短按一步和长按重复。
键盘 keyboard bit4 发布 Shift 摩擦轮请求；Ctrl 和鼠标右键不会代替此请求。两种输入使用同一帧时间戳，离线一起失效。

底盘命令也来自本周期唯一快照：CH2/CH3、keyboard、可用性及真实接收 HAL ms。`ChassisCommand_Submit` 在发布端捕获 bit5 Ctrl 按下事件，底盘任务按停机→左摇杆平移→键盘循环；上电/重连须先释放再按。键盘 W/S、A/D、Q/E；两个拨杆只解码记录，不改变模式或许可。底盘不再次读取会清空鼠标累计量的 `Dbus_GetSnapshot`。四个邮箱分别复制，不保证四个控制任务同时执行新命令。

中断优先级为 5，满足 FreeRTOS `FromISR` 规则；USART3 不调用 `HAL_UART_IRQHandler`，
因为 HAL 单缓冲接收会 Abort 自定义 DBM。半帧 IDLE、UART/DMA 错误只请求任务恢复，
不会在 ISR 中打印或阻塞。驱动没有 CRC，字段范围校验只能过滤明显错位，不能替代实机
链路检查。

任务配置位于 `Core/Inc/task/task_dbus/task_dbus_config.h`：摇杆反向调
`DBUS_*_INPUT_SIGN`，回中漂移调 `DBUS_STICK_DEADBAND_RAW`，满杆速度调对应轴
`*_MAX_COMMAND_SPEED_RPM`；输入方向和 GM6020 电流方向是两个坐标系，不能混改。
虚拟鼠标总开关和公共输出上限也在该配置头中；Yaw/Pitch 的增益、方向、保持和回中分别配置。
当前参考周期14 ms、Yaw/Pitch参考周期增益均0.5‰/count、缺帧保持/回中14/14 ms、上限100‰；两轴满输入40 rpm时，鼠标单独的目标移动速度上限4 rpm（24°/s）。方向-1/+1保留，摇杆及闭环纠偏不受此鼠标上限约束。测速公式、首帧/多帧行为与实测对照见[鼠标模块](../mouse_virtual_joystick/README.md)。
增益可设 `0.1f`、`0.05f` 或 `0.01f`；测速、回中和速度命令保留小数，图表按整数协议输出。关闭虚拟鼠标后只由摇杆产生速度，
不回退到旧的逐周期鼠标映射。算法接口、状态定义和调参说明见
`doc/modules/mouse_virtual_joystick/README.md`。

## 串口遥测与图表帧

USART1 是日志输出口，USART3 只接收 DBUS。`Core/Inc/app/log/log_config.h` 提供编译期
开关：`LOG_GLOBAL_ENABLE` 和 `LOG_USART1_ENABLE` 是总门，`LOG_DBUS_TEXT_ENABLE` 控制
完整文本，`LOG_DBUS_CHART_ENABLE` 控制图表帧，`LOG_TASK_ENABLE` 和 `LOG_TEST_ENABLE`
分别控制正式任务与硬件测试诊断，并与 `LOG_YAW_ENABLE/LOG_PITCH_ENABLE/LOG_FEED_MOTOR_ENABLE`
配合。所有输出直接使用 `app/log/log.h` 的 `LOG_TRY_PRINTF`；关闭分类后对应格式参数不求值、不占用 DMA。

默认每 `DBUS_TASK_LOG_PERIOD_MS=100 ms` 尝试一次；周期由 DBUS 任务配置独立管理。文本和图表启用时合并为一次 USART1 DMA
提交；USART1 忙或文本超过 768 字节时整条丢弃，下一个周期重试。DBUS 任务仍使用同一份
快照发布命令，日志不会刷新命令时间戳。

图表格式兼容 `hehe.html` 的文本 CSV 解析：

```text
ch:CH0,CH1,CH2,CH3,CH4,virtual_mouse_x,virtual_mouse_y,mouse_z,status,keyboard\n
```

通道 0~4 是已减中心值的 DBUS 摇杆，通道 5/6 是虚拟鼠标 X/Y，通道 7 是原始鼠标 Z，
通道 8 是状态位图，通道 9 是键盘位图。原始鼠标 X/Y 保留在完整文本日志中。状态位图
bit0~1 为左拨杆，bit2~3 为右拨杆，bit4/5 为鼠标左/右键。
文本日志还包含拨杆、鼠标、键盘、在线状态、帧年龄、错误计数和 Yaw/Pitch/fire 派生命令。
新增 `virtual_mouse_x_x100/y_x100`（‰×100）、`mouse_virtual_state`、`mouse_virtual_x_state/y_state`、`mouse_frame_sequence`、
`mouse_delta_x/y`、`mouse_delta_frames` 和 `frame_overruns`；原始鼠标字段保持 count 单位。
合法帧计数同时作为去重序号，打印不改变输入有效期。
离线时保留最后合法数据用于诊断，但 `online=0`，命令邮箱同时失效。
完整配置、键盘位映射、DMA 带宽及多多盒子设置见 `doc/modules/log/README.md`。

验证：临时主机测试覆盖 11 位通道高位、鼠标有符号值、拨杆编码、M0/M1 所有权、IDLE
顺序、错误恢复、时间回绕、覆盖邮箱和双轴命令超时；`cmake --preset Debug` 与构建通过。
本轮临时替身额外覆盖实际任务的虚拟鼠标、零位移回中、离线清零、DMA 忙、10 通道解析和
32 组日志/虚拟开关运行；原始 USART3 DMA/IRQ 未改变。实际鼠标手感和摆动仍需上板验证。
