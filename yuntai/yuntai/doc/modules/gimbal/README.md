# 通用 GM6020 云台轴

## 职责与依赖

`Core/Inc/app/gimbal/`、`Core/Src/app/gimbal/` 保存正式共用实现：

- `gimbal_command.h`：轴无关相对速度命令数据，不发布 Yaw/Pitch 命令。
- `gimbal_control`：目标积分、位置 PID、速度 PID、算法补偿合成、限幅和电流 Ramp，复用 algorithm 中的 PID/滤波/Ramp/重力补偿。
- 前馈系数、位置 I/D、速度 D 及两级积分独立限幅由各轴配置提供；速度滤波权重独立设置，测试与正式共用这些参数。
- 软件限位由 `gimbal_control` 做无状态命令过滤；边界处只屏蔽继续向外的速度目标，仍按最后目标运行角度环、速度环和 Ramp。
- `gimbal_axis`：初始化、每周期一次快照、共用运行流程、输出和日志适配。

只在任务上下文运行，没有具体任务头文件依赖。反馈由 CAN ISR 更新，ISR 不运行控制或打印。

## API 与数据流

`GimbalAxis_Init(&axis, &config)` 复制本轴电机、标定和控制参数；角度范围与首帧参考
自动从标定生成。标定无效允许只读模式，闭环始终零输出。

`GimbalAxis_RunCycle()` 接收已处理超时的相对命令；`GimbalAxis_RunFixedTarget()` 接收固定连续角度。
两者调用同一运行流程；每周期 Process → GetSnapshot 一次 → 检查配置/新鲜度 → 控制 → 提交。
首帧、反馈恢复和配置无效时走安全零输出；反馈恢复只清动态控制历史，不覆盖最后目标。边界状态只过滤继续向外的命令，明确向内脱离同周期提交正常闭环电流。固定目标越界直接零输出。

`axis.cycle` 包含唯一快照、计算结果、最终目标电流、许可及 CAN 提交结果，日志复用它。
任务和固定目标测试使用 `app/log/gimbal_log.h` 的共用格式，从本周期 `axis->cycle` 生成日志参数，
直接调用 `LOG_TRY_PRINTF()`；不重新读驱动，忙时返回 false，下次周期重试。Yaw/Pitch 日志开关独立。
轴运行时会把 GM6020 原始转速按该轴独立的反馈速度符号映射为连续角度的逻辑转速；反馈方向和电流方向不能共用一个符号，否则下滑可能被误认为向内运动。

## 恢复语义

正式相对命令和固定目标都在边界处过滤继续向外的意图；回中保持最后目标，反向输入同周期脱离。反馈掉线清零，恢复反馈后只重置动态控制历史，不改写最后目标。

## 坐标与调参

8192 计数/圈；目标以标定中位为参考。首帧按“离中心最近的单圈解释”映射，启动位置需要距中心
不到半圈；这不是机械总范围必须小于半圈。存在传动机构必须记录电机轴/机构轴传动比。

控制器和日志对象按轴独立。标定与增益放各自任务配置，测试仅提供输入意图，
确认参数后切换正式入口即可。默认数字未实测，轴保持是机械相对角保持，不是世界系姿态稳定。

Pitch 与 Yaw 的控制参数按负载分开。当前 Pitch 的自动重力补偿开关为 1，
由独立算法模块叠加 `bias + amplitude*cos(angle_offset)`；Yaw 使用同一模块但禁用。
补偿与闭环电流合成后统一限幅并经过 Ramp，方向由独立的补偿符号控制。
Pitch 与 Yaw 都保留反馈掉线、标定有效性和总电流上限检查；限位处不切换零电流。
Yaw 与 Pitch 都不再启用堵转候选、锁存和恢复流程。

两轴软件限位在线时不再把输出清零：达到或越过边界时忽略继续向外的输入，
保留最后一次有效控制形成的目标位置；没有新命令时目标不移动，任务仍周期运行闭环并提交对应电流。
只有反馈掉线、参数无效或目标无效才立即清零。

速度目标为 `clamp(位置 P × 角度误差 + 位置 I × 误差积分 + 位置 D × 角度误差变化率 + 前馈系数 × 命令速度)`；
位置 D 的误差变化率由目标角速度减实际滤波速度换算得到，固定目标时就是实际速度的阻尼项。
目标积分不乘前馈系数；固定目标的命令速度为零，前馈贡献为零。速度环 D 由轴配置选择；积分限幅
允许 0，但不可大于总电流限幅。运行时拒绝非有限/负增益及无效滤波权重，拒绝后保持零输出。

## 验证

用临时主机 HAL 替身编译实际 C 源码，验证回绕、双轴槽位隔离、目标/保持/Ramp、方向限位、
快照失败、限位过滤、最后目标保持和反向输入、掉线安全周期及 UART DMA 缓冲区所有权。
临时验证文件保存在系统 Temp，不加入工程；主机检查不能证明实际电机方向、机械安全范围或负载增益正确。

## 控制参数单位与饱和检查

每轴的调参宏保留在对应任务配置；输入鼠标灵敏度在 DBUS 任务配置。
位置环误差使用连续编码器 count，速度目标使用 rpm，电流使用 GM6020 原始值。
位置 P 的单项饱和阈值为 `MAX_SPEED_TARGET_RPM/POSITION_KP_RPM_PER_RAW` count；
速度 P 的单项饱和阈值为 `MAX_CURRENT_RAW/SPEED_KP_CURRENT_PER_RPM` rpm。
I、D、前馈和重力补偿会占用输出余量，实际饱和可能更早。

命令速度既积分目标角度，也经前馈参与目标速度。只调整前馈不改变目标积分；
固定目标速度为零时没有速度前馈。按实际 dt 积分，电流斜率使用 raw/s。
官方例程的 rad/s 或每周期积分增益须先换单位，再写入任务配置：
`rad/s × 60/(2π)` 得 rpm，`count × 2π/8192` 得 rad。
先检查速度和电流是否饱和，再逐项调增益；饱和时继续加 P 只会增加力矩或温升。
