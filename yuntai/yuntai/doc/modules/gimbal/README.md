# 通用 GM6020 云台轴

## 职责与依赖

`Core/Inc/app/gimbal/`、`Core/Src/app/gimbal/` 保存正式共用实现：

- `gimbal_command.h`：轴无关相对速度命令数据，不发布 Yaw/Pitch 命令。
- `gimbal_control`：目标积分、角度 P、速度 PI、限幅和电流 Ramp，复用 algorithm 中的 PID/滤波/Ramp。
- `gimbal_protection`：启动/换向宽限、堵转连续证据、软件边界与方向相关恢复。
- `gimbal_axis`：初始化、每周期一次快照、共用运行流程、保护后输出和日志适配。

只在任务上下文运行，没有具体任务头文件依赖。反馈由 CAN ISR 更新，ISR 不运行控制或打印。

## API 与数据流

`GimbalAxis_Init(&axis, &config)` 复制本轴电机、标定、控制和保护参数；角度范围与首帧参考
自动从标定生成。标定无效允许只读模式，闭环始终零输出。

`GimbalAxis_RunCycle()` 接收已处理超时的相对命令；`GimbalAxis_RunFixedTarget()` 接收固定连续角度。
两者调用同一运行流程；每周期 Process → GetSnapshot 一次 → 检查配置/新鲜度 → 控制 → 保护 → 提交。
首帧、反馈恢复或保护解除经过零输出周期，清积分与 Ramp。固定目标越界不钳到边界继续施力。

`axis.cycle` 包含唯一快照、计算结果、最终目标电流、许可及 CAN 提交结果，日志复用它。
`GimbalAxis_TryLog()` 不重新读驱动，忙时返回 false；保存最近一次保护进入/解除事件便于重试。

## 恢复语义

相对命令：同向保持零电流，松手/反向且电流下降持续确认后解除；目标重置到当前实际角度。
固定目标：零命令不表示松手，只有反向实测位移达到配置距离、仍在范围内、反馈新鲜且电流下降，
持续确认后才恢复原固定目标。`stall_requires_manual_release` 在触发时保存，掉线不清除；
掉线中断连续确认计时，不能用等待时间证明障碍已消失。

## 坐标与调参

8192 计数/圈；目标以标定中位为参考。首帧按“离中心最近的单圈解释”映射，启动位置需要距中心
不到半圈；这不是机械总范围必须小于半圈。存在传动机构必须记录电机轴/机构轴传动比。

控制器、保护和日志对象按轴独立。标定与增益放各自任务配置，测试仅提供输入意图，
确认参数后切换正式入口即可。默认数字未实测，轴保持是机械相对角保持，不是世界系姿态稳定。

## 验证

用临时主机 HAL 替身编译实际 C 源码，验证回绕、双轴槽位隔离、目标/保持/Ramp、方向限位、
快照失败、堵转锁存/手动恢复/再触发、掉线安全周期及 UART DMA 缓冲区所有权。
临时验证文件自动清理；主机检查不能证明实际电机方向、机械安全范围或负载增益正确。
