## 需要区分的路径

1. IMU与编码器正向不一致：固定底座、手动右转后比较累计Yaw和连续编码器的增量；异号才支持调整惯性反馈符号。IMU显示右转为正不等于电机编码器也右转为正。
2. 输入持续或映射错误：当前鼠标是虚拟速度，按位移累计，最后非零输入后保持70 ms、再70 ms衰减；不是一次固定角度命令。若需要后续带电复测，必须同时记录目标/输入/前馈/编码器与电流，不能只看1 Hz姿态。
3. 速度反馈/控制响应：Yaw仍沿用速度D=1.5 raw·s/rpm和既有参数，换成陀螺测速后噪声及动态需重新评估；若方向一致但响应异常，再据同步日志判断，不能先增加P或换电流方向。
4. INS采集故障：独立记录失败出口与DMA阶段，区分发生时序；不放宽10 ms新鲜度或2 ms事务超时来掩盖问题。

## 本次诊断改动

`task_ins_runtime.c`仅增加任务私有诊断：记录上次采集故障、次数/时刻、初始化尝试数、DMA失败阶段和Abort前SPI错误位。普通1 Hz姿态日志增加HAL时间及样本序号；磁诊断分支保留原格式，避免与长磁日志合并超出768字节。`上次采集故障`在成功恢复后保留，须结合当前状态及故障次数变化读取，不表示当前仍故障。阶段与错误记录不能改变控制/恢复路径；默认控制配置不变。

| 上次采集故障 | 任务失败出口 |
| --- | --- |
| 0 | 尚无任务采集出口记录；不据此排除INS内部解算故障 |
| 1 | BMI初始化、ID或配置回读失败 |
| 2 | 相邻陀螺边沿HAL间隔超时 |
| 3 / 4 / 5 | 陀螺 / 加计 / 温度DMA读取失败 |
| 6 | DWT积分dt非法 |
| 7 | 处理时陀螺样本过期 |
| 8 | 启动后一直没有加计样本 |
| 9 | 加计样本过期 |
| 10 | 等待陀螺新边沿超时 |

`DMA失败阶段`：0无相关DMA失败，1启动失败，2等待超时，3完成状态/解析失败。`SPI错误`为HAL错误位，0也不能排除通知/中断或超时问题；必须先捕获再Abort，HAL清理可能撤销错误位。

GM6020只读标定日志增加HAL毫秒时间戳，保留其原有单周期唯一快照、零电流和CAN提交行为；不在日志中重新读编码器。CAN与INS不是硬件同步采样，因此方向对照使用停止后保持窗口。
