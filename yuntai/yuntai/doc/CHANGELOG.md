# 变更记录

## 2026-10-03（GM6020 双轴通用调参与快照一致性）

- 新增 `app/gimbal/gimbal_axis`，Yaw/Pitch 的 GM6020 硬件标定和固定目标角度环共用正式控制、Ramp、限位和堵转保护组合。
- 测试接口改为传入电机句柄、独立标定配置、轴运行时和测试实例；消除文件级共享日志状态，Pitch 已接入相同两种硬件测试。
- 控制、保护和日志复用同一周期 `Gm6020_GetSnapshot()` 快照；新增固定目标堵转的手动反向移开恢复条件。
- 标定日志增加中位、两侧边界和零电流操作提示；USART DMA 日志改为非阻塞并修复长度类型和缓冲区覆盖风险。
- 从 Yaw 迁移控制与保护源文件至 app/gimbal，删除旧重复实现；Yaw 正式命令继续通过原抽象接口提交，Pitch 关闭测试时保持零输出。
- GM6020 聚合帧构建与 HAL 提交在短临界区完成，保留另一轴槽位；驱动限位允许向内脱离，首帧 0 ms 以独立有效标志判断。
- 固定目标堵转恢复默认反向 114 计数与低电流持续 100 ms；掉线保留锁存，解除清积分/Ramp 并执行一个零输出周期，数值仅是台架起点。
- 两轴标定、固定角度、关闭测试分支均构建通过；实际 C 源码的临时主机验证覆盖回绕/双轴槽位/快照/保护时序及 DMA 重入、长日志和提交失败；临时文件已清理。git diff --check 通过，新文件额外检查宏/成员注释及行尾空白。
- 默认 Debug 产物仍为两轴零电流标定；实际机械边界、方向、恢复距离和保护阈值仍需上板验证。

- 修正 C610 初始化阶段的假在线：新增 `feedback_received`，未收到真实反馈时保持离线和零输出；日志新增反馈有效标志与反馈年龄。
- 为项目自建和新增宏补充用途、单位、协议来源和边界注释，并把该要求写入 `AGENTS.md`。

- （历史记录，GM6020 结论已由 2026-10-03 官方手册核对纠正）按参考工程重新核对电机电流范围：当时误确认 GM6020 的 ±30000，将 C610/M2006 的钳位从 ±16384 修正为 ±10000，并在规则中区分 C620/3508 的 ±16384。
- 按 Yaw 工程化重构计划拆分通用 PID、Ramp、低通滤波和 `task_yaw` 的命令/控制/保护/运行时模块，并把任务入口迁移到独立目录。

- 精简供弹电机任务命名：仅保留 FreeRTOS 入口的 `task_feed_motor` 前缀，模块内部统一使用 `FEED_MOTOR`/`FeedMotor`。
- 新增 `gm6020` 云台电机驱动：支持 `0x205`/`0x206` 反馈、连续角度、软件角度限位和速度/电流堵转保护；电流控制帧与电流范围随后按官方手册在 2026-10-03 修正为 `0x1FE/0x2FE` 和 `±16384`。

- 更新 `yuntai.ioc`：创建短名称任务 `task_yaw`（云台底盘水平轴）和 `task_pitch`（发射云台纵向轴），并在生成代码中保留安全空的弱入口。
- 修正 CubeMX FreeRTOS 任务配置格式：多个任务必须放在同一个 `FREERTOS.Tasks01` 值中，以分号分隔；此前拆成 `Tasks02/Tasks03` 会导致 CubeMX 只显示部分任务。
- 早期版本曾新增单文件 Yaw 轴低电流左右往返自循环测试；本次已将其替换为目录化闭环控制和任务层保护。
- 修正电机任务超时基准：CAN ISR 使用 `HAL_GetTick()` 记录反馈时间，Yaw 和供弹任务的 `Process()` 现在也使用 `HAL_GetTick()` 判断超时，避免 `xTaskGetTickCount()` 与 HAL Tick 起始值不同造成假离线。
- 修正 GM6020/Yaw 堵转误判：保护逻辑现在同时检查目标电流和反馈实际电流；仅有目标电流但反馈电流尚未建立时不再直接锁存 `physical_blocked`。
- 完善 GM6020/Yaw 堵转恢复：保护不会按时间盲目重试；手动移开云台、角度变化达到恢复阈值且实际电流降下来后，自动清除 `BLOCKED` 并回到安全等待阶段。
- 新增项目规则：每次修复新 Bug 必须记录根因、防复发约束和实际验证范围。建立 `doc/BUG_FIXES.md`，收录时基混用、Yaw 堵转误判/恢复和 CubeMX 任务字段错误；补充时间基准与保护完整路径的检查要求，并修正注释规范中 Tick 回绕的无符号差值说明。本次只修改规则与文档。
