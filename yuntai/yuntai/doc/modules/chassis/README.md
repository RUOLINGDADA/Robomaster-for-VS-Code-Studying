# 四轮底盘纯控制

`Core/Inc|Src/app/chassis/chassis_control.h/.c` 只接受配置、模式、命令值和四轮反馈副本，输出逻辑目标 rpm 与电流 raw。它不包含任务配置，不读 DBUS，不发送 CAN。对象由唯一底盘任务串行调用；四个独立速度 PID 复用本项目 `algorithm/pid`。

`ChassisControl_Init()` 校验并值复制有限参数，初始化四个 PID。`Reset()` 清 PID/三轴曲线历史并保留配置。`Update()` 使用实际正 `dt_s`，非法参数返回 false 并清历史/输出；STOP 直接零电流。任务层负责模式切换、超时和总线故障。

## 坐标与混控

数组顺序为 ID1 右前、ID2 左前、ID3 左后、ID4 右后，均为转子 rpm。Vx 正向为右，Vy 正向为前，Wz 为源工程的旋转符号；具体机械方向待架空确认。

```text
rpm1 = clamp(Vy - Vx - Wz, ±6000)
rpm2 = clamp(Vy + Vx + Wz, ±6000)
rpm3 = clamp(Vy - Vx + Wz, ±6000)
rpm4 = clamp(Vy + Vx - Wz, ±6000)
```

逐轮限幅保留源普通底盘算法，不做整体比例归一化。安装方向 `{-1,+1,+1,-1}` 由运行时同时用于反馈与电流变换；纯控制只计算逻辑方向。不能只改发送符号而不改反馈，否则闭环方向相反。

摇杆模式使用 CH2 为 Vx、CH3 为 Vy，严格 `-30<raw<30` 回中，死区外 `raw/660×6000`，Wz 恒为零。键盘模式完全忽略摇杆，D/A、W/S、E/Q 分别产生 Vx/Vy/Wz 的正/负目标；同轴相反键抵消，松键立即清该轴曲线及目标。拨杆、Ctrl、鼠标、Shift 不在本层判定。

## 键盘曲线

三个轴分别保存曲线历史。0.20 s 到达一次过渡幅度的 1/3；1.00 s 到达终点，期间使用源工程平滑对数段。若当前速度与新目标异号，先用同一曲线过渡到零；到零周期仍输出零，下一周期才开始相反方向。零目标表示速度环制动，不等于停机零电流。

令 `r=1/3, t1=0.2 s, t3=1 s, a=4`，归一化曲线为：

```text
t<t1: f=r*t/t1
t1≤t<t3: u=(t-t1)/(t3-t1), h=1-u, L=ln(1+a)
  C=ln(1+a*u)/L
    + (r*(t3-t1)/(t1*(1-r))-a/L)*u*h²
    + a/((1+a)*L)*u²*h
  f=clamp(r+(1-r)*C, r, 1)
t≥t3: f=1
value=start+(target-start)*f
```

两端修正保持端点值，使对数段与直线段斜率衔接并以零斜率收尾。实际 HAL 时间差推进曲线；不是每调用一次固定加 2 ms。改形状参数后应复核单调性。

## 速度 PID 与参数来源

源工程入口为 `MyChassis1-main/MyChassis1-main/Core/Src/app/chassis_control/chassis_control.c` 及对应配置。仅移植普通混控和曲线，未移植小陀螺、自动正反转、源 PID 副本、调参和参数存储。

底盘调用本项目 `Pid_Init` 后开启 `Pid_ConfigureIntegral(0.01f,true)`：积分增量为 `Ki*(e+e_prev)/2*dt/(1+0.01*abs(e))`；首帧 previous=e。积分钳位 ±1000 raw，按实际积分增量判断是否继续推动输出饱和，Reset 保留两个选项。默认 PID 仍为矩形积分、权重 1，云台调用兼容。

源参数 Kp=4 raw/rpm、Ki=2 raw/(rpm*s)、Kd=0、目标 ±6000 rpm、实际电流 ±4915 raw。纯 P 在 `4915/4=1228.75 rpm` 误差即饱和。6000 是转子上限，不是底盘线速度；这些数值作为移植起点，稳定性、轮子尺寸、减速比和带载温升待实测。所有默认值与覆盖范围见 [任务配置表](../task_chassis/README.md)。

每轮反馈独立判断：离线或非有限速度只清该轮 PID/电流，其余在线轮继续控制；恢复轮在任务层清历史后重新计算。临时测试覆盖混控、方向、目标限幅、曲线单调性/端点/反向/松键、零速度制动、单轮失效。构建通过不能替代实际四轮方向与闭环整定。
