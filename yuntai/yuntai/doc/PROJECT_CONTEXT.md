# yuntai 工程上下文

## 当前边界

- 本文档对应目录：`yuntai/yuntai`。
- 同级父目录包含多个独立学习示例；它们是参考资料，不属于本工程的构建输入。
- `can_example` 是当前代码风格和 RoboMaster CAN 设备封装的主要参考工程。

## 已确认的工程状态

- MCU/芯片：STM32F407，使用 STM32 HAL 和 CMSIS。
- RTOS：FreeRTOS，工程同时生成了 CMSIS-RTOS V2 适配层。
- 构建：CMake + Ninja 预设，工程名为 `yuntai`。
- 生成代码包含 `main.c`、`freertos.c`、GPIO/CAN/UART 初始化和 FreeRTOS 任务创建；业务强入口通过 CMake 从 `bsp/`、`algorithm/` 和 `task/` 目录接入，`freertos.c` 仅保留弱兜底。
- 目前应把新增业务代码放入 `Core/Inc`、`Core/Src` 的 `bsp/`、`algorithm/`、`app/<feature>/` 或 `task/<task_name>/` 子目录，并接入 CMake。
- 当前已接入 `bsp/gm6020` GM6020 驱动、通用 PID/Ramp/低通算法和 `task_yaw` 模块；`.ioc` 已创建 `task_yaw`（云台底盘水平轴，反馈 ID `0x205`）和 `task_pitch`（发射云台纵向轴，反馈 ID `0x206`）。Yaw/Pitch 使用 DBUS 相对速度命令、各轴已有标定和级联闭环。默认运行正式模式；软件边界只过滤继续向外的命令，零速度保持角度，反馈离线归零。当前不含动态堵转或锁存。
- 所有串口日志直接使用 `app/log/log.h` 的统一宏与 `app/log/log.c` 的唯一 USART1 DMA 后端。Yaw、Pitch 和供弹开关独立；共用轴测试从任务接收分类，参数关闭后不求值。UART 初始化仍由 CubeMX 维护。
- `task_feed_motor` 已按任务目录拆为入口、命令、控制和运行时；正式路径由 DBUS 鼠标左键驱动单发/连发状态机。单发先预旋双 C615，两路 PWM 达到活动值后以固定电流驱动 M2006；上弹和停滞确认期间摩擦轮持续活动，停滞确认结束后停止 M2006 并开始单发保持。长按阈值达到且第一发完成后进入 C610+C615 连发。C610 只读手动角度反馈测试仅在 `FEED_MOTOR_ANGLE_STEP_TEST_ENABLE` 显式开启时使用。阶段/日志配置以毫秒保存，使用前转换为 FreeRTOS Tick。C610 只有收到至少一帧合法反馈后才报告在线，避免初始化零时间戳造成假在线。
- 永久硬件测试只保留 `bsp/gm6020` 的手动角度标定、固定目标角度环、`bsp/c610_m2006` 的只读手动角度步长测量和独立 C615 PWM 测试；C610 自循环及 C615 软件校准已删除。纯协议、PID、Ramp、回绕和限幅验证使用临时脚本，不建立 `Core/Inc/test` 或 `Core/Src/test`。
- `app/gimbal/gimbal_axis.c` 提供 Yaw/Pitch 共用的 GM6020 快照、角度/速度环、Ramp 和保护组合；两个任务只保存自己的轴句柄、配置和测试状态。固定角度测试日志复用运行时同一周期快照。
- DBUS 已接入 USART3 PC11（100000、9B+偶校验、DMA1 Stream1），`task_dbus` 每 2 ms 发布右摇杆 CH0/CH1 与鼠标虚拟摇杆叠加的 Yaw/Pitch 速度；鼠标相对位移按合法帧去重，以浮点增益累计。增益、保持和线性回中参数集中在 `task_dbus_config.h`，X/Y 独立计时，仅在速度发布时取整。鼠标左键发布供弹命令。DBUS 掉线 100 ms 立即清虚拟鼠标并停止两轴目标积分，两轴继续保持最后目标并计算补偿；供弹停机。电机 CAN 反馈失效时两轴直接发零。

## 目标架构

```text
硬件/协议驱动（bsp） -> 通用算法（algorithm） -> 共用控制/保护（app/gimbal） -> 任务配置/命令适配（task）
```

驱动负责寄存器、HAL、协议帧解析和最小状态；算法只做数值计算；共用应用模块组合驱动、控制和保护，任务目录适配本轴配置与输入；任务入口负责调度。业务逻辑不得直接散落在 HAL 回调中。

## 参考代码边界

`can_example` 中的 C620 驱动展示了句柄、命令表、CAN 帧和回调的写法，但当前工程只按实际功能采用其中的必要部分。没有明确用途的错误枚举、回调、日志和状态层不应直接复制。

## 交付要求

每次改动都要说明：改动文件、公开接口、任务/中断上下文、硬件假设、构建或静态检查结果、未验证风险和后续问题。需求未明确时，把问题写入 `OPEN_QUESTIONS.md` 并在回复中直接询问。


## 双轴调参默认值与验证

- Yaw/Pitch 当前默认 `*_HARDWARE_TEST_MODE_OFF`，已有标定有效标志均为 1；本轮沿用已有实机配置，不自动重做标定。
- Yaw 固定目标相对中位默认 +30°，Pitch 默认 0°；只有实机填好本轴标定并切换角度模式后才可能输出。
- 软件边界过滤向外速度并保留闭环，反向命令可同周期脱离；不实现动态堵转检测或锁存。
- 本轮使用临时 HAL 替身验证 DBUS 鼠标解析与叠加、C615 PWM 范围和 Ramp、供弹预旋/到位/间隔、8192 count 回绕、释放停机和通信超时；1000 Hz 与 500 Hz Tick 均通过，临时文件未提交。
- 软件检查不代替上板标定：新增摩擦轮方向、PWM 行程、温升及 M2006 每发角度仍待实测；既有云台标定和控制参数由对应轴配置保存。
