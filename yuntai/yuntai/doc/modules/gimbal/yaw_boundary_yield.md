# Yaw 边界让步与反转恢复

## 现象与依据

用户确认 IMU 正常，Yaw 机械行程约 180°。底盘沿一个方向继续转动，云台到达挡块后，即使底盘反转仍会持续顶住挡块。

`ins.c` 正确展开相邻航向并累计 `yaw_total_deg`。原 `GimbalControl_UpdateFeedback()` 仅过滤人工增量与前馈，零输入不修改目标，仍直接使用 `target-angle` 求误差。机械挡块使原惯性目标不可达；底盘继续一圈会产生约 8192 count 的控制误差。以当前位置 Kp=0.01 rpm/count，单圈误差就请求约 81.92 rpm，速度 P=200 raw/rpm 在静止时已超出 7000 raw 电流上限。小角度反转仍留下大部分旧误差。

这是代码可确认的目标不可达问题。当前 Yaw 位置 Ki=0，不应称为位置积分饱和；速度积分、Ramp 和机电动态可额外延迟恢复。主机验证不证明各因素在实机中的占比。

## 当前实现与接口

- `YAW_BOUNDARY_YIELD_ENABLE=1`：无量纲 0/1，默认正式 Yaw 启用；0 恢复只过滤人工命令的策略。仍使用 115～4085 count，不增加内缩，不改 PID、测速符号、鼠标映射或电流参数。
- 共用配置新增 `boundary_yield_enabled`，默认零初始化为关闭；Pitch 未启用。固定机械角测试由运行时强制关闭，控制器也检查 `fixed_target`。
- 本周期编码器达到/越过下界且目标误差为负，或达到/越过上界且误差为正时，将目标更新为当前控制角。先让步，再接受向内人工增量。向内旧目标继续保留；行程内零输入保持原目标。
- IMU 继续累计真实航向，不清零、不钳位，也不将误差折返到 ±180°。让步修改的是控制目标，不是姿态估计。底盘反转后保持让步形成的新航向，不追赶原航向、不自动回中。
- 边界状态变化时用真实速度初始化滤波，并取消速度 PID 的旧微分参考；不反复重置整个控制器。边界内持续清除两级向外积分，保留向内积分。
- PID、重力补偿、限流和 Ramp 之后执行逻辑电流方向门。下界拒绝负电流，上界拒绝正电流；置零时同步 Ramp 历史，随后才转换电机电流符号。有效零电流仍可正常提交，方向限制不等于输出许可失效。
- 范围外启动捕获实际位置，不自动拉回；编码器降级也执行该单向策略。IMU 切换、100 ms 资格窗口、80°/75°奇异区保护、CAN/标定/参数故障规则保持。CAN 恢复的安全零周期之后，计算输出前重新处理不可达目标。

控制与日志使用相同周期的唯一 CAN/INS 快照；新增状态由所属轴任务独占，无新增 ISR 状态或 IPC。

## 日志与主机验证

共用日志新增 `目标让步`、`向外电流受限`，分别对应 `target_yielded`、`outward_current_limited`。它们是本周期事件，需与 `人工受限`、`输出许可`、`CAN提交` 分开读取。速度环电流是方向门之前的诊断；目标电流为 Ramp 和方向门之后，提交电流再应用电机符号。串口忙时允许丢日志，不改变控制。

当前源码 `LOG_TASK_ENABLE=0`、`LOG_YAW_ENABLE=0`、`LOG_DBUS_TRACE_ENABLE=0`，本次不改用户开关。实机观察时由用户在构建前将前两项设 1，保持输入采集独占开关为 0；USART1 使用 921600/8N1。默认 500 ms 日志可能错过单个 2 ms 事件，必要时减小 Yaw 日志间隔并检查带宽。

2026-10-23：使用临时 Windows 主机 HAL 替身编译实际控制器、轴运行时、两轴任务配置、PID/滤波/Ramp/补偿及 GM6020 驱动。默认日志配置 18217 项、开启双轴正式日志 18219 项检查分别通过，每组 3015 次 CAN 提交（含原人工限位、反馈切换、双轴槽位和只读标定回归）；极值日志夹具 604 字节，小于 768 字节缓冲区。

覆盖两侧边界后再转 360°/720°及小角度反转；让步和向内输入同周期；边界外启动；向外测速、积分和旧 Ramp；向内积分保留；行程内保持与航向回绕；IMU 无效/重置/奇异区和 CAN 恢复；电机符号映射；Pitch 与固定目标独立行为。

临时文件位于系统 Temp 的 `yuntai_yaw_boundary_5d2b48e009ad41e2a60cac64c09efbc9`，不加入工程。仅生成主机验证程序，没有 ARM 编译、固件或独立固件构建目录。

## 用户上板验收

1. 在 VS Code 构建并烧录最新源码。先在中间位置确认零输入自稳，再缓慢接近下界和上界。
2. 近水平底盘继续沿原方向旋转一圈、两圈。确认边界处目标随实际姿态让步、无向外目标电流；随后小角度反转，应开始向内纠偏，不等待旧转角被抵消。
3. 两侧分别检查向外人工命令被拒绝、向内命令当周期接受，范围外启动无自动回中；再检查正常 Pitch 活动下的 Yaw 恢复与 Pitch 原行为。
4. 检查离开挡块的延迟、边界附近抖动、动态超调、电流及温升。软件立即允许向内不代表机构瞬间离开；当前边界未增加制动距离，不保证不接触挡块。

大幅底盘倾斜下的完整三维可达性、六轴长期漂移和实际带载精度仍待实测，本次不实现动态堵转检测。
